
# 🧠 Suicide Analysis in India (2001–2012) – Tableau Dashboard

This project presents an interactive Tableau dashboard that visualizes the patterns, causes, and demographic breakdowns of suicide cases reported in India from 2001 to 2012. The goal is to highlight concerning trends and facilitate awareness through data-driven storytelling.

---

## 📊 Dashboard Features

The dashboard provides a comprehensive overview of suicide cases across multiple dimensions:

- **📍 State-wise Cases**: Identifies Maharashtra as the state with the highest number of cases (9,01,945).
- **🔢 Total Cases Nationwide**: Visualizes total suicide cases during the 12-year period (~29,11,862).
- **📌 Leading Cause**: Family problems account for the highest number of cases (65,341).
- **🪢 Common Means Adopted**: Hanging is the most frequent method (~61,651 cases).
- **👥 Affected Age Group**: The age group 15–29 is the most vulnerable (~2,04,870 cases).
- **📚 Education Level**: Primary education is the most reported level among individuals (~48,474 cases).
- **🚻 Gender Distribution**: Male suicide cases significantly outnumber female cases.
- **📈 Age Group Breakdown**: Distribution shown across all age brackets.
- **📊 Other Causes of Suicide**: Includes mental illness, addiction, financial problems, and more.
- **📅 Year-wise Trend**: Line/bar chart showing how total cases evolved from 2001 to 2012.
- **🔎 Interactive Filters**: Allows users to filter by year and other parameters for dynamic insights.

---

## 📁 Data Source

- **Dataset**: Suicide statistics from India, likely sourced from [National Crime Records Bureau (NCRB)](https://ncrb.gov.in/)
- **Format**: CSV/Excel
- **Time Range**: 2001–2012

## 🎯 Key Insights

- Young adults (15–29) are the most affected age group.
- Family issues remain a dominant reason for suicide across states.
- Educational background and gender play significant roles in the distribution.
- States like Maharashtra show disproportionately high numbers, demanding policy attention.
- Trend lines from 2001 to 2012 indicate areas requiring targeted interventions.
